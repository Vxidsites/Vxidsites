# VxidSites 🚀

Welcome to **VxidSites**, the official developer portfolio and hub for Vxid's projects, scripts, games, and content. This website serves as a central location for users to discover software tools, read the latest changelogs, and securely download optimization scripts.

## 🌟 Features
* **Modern UI**: A sleek, dark-themed interface built using custom glassmorphism CSS, proximity-hover sidebars, and smooth micro-animations.
* **Single Page Application (SPA)**: Custom hash-based routing built entirely in Vanilla JS for instantaneous page loads without reloading the browser.
* **Software Hub**: A built-in download center that dynamically filters between scripts, tools, and utilities.
* **Project Deep-Dives**: Detailed breakdown pages for software (including full feature lists and direct download links).
* **YouTube Integration**: Direct links to the latest video tutorials and content.
